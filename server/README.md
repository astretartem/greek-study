# Сервер синхронизации прогресса

Сервер выполняет две задачи.

1. **Сигнальный сервер** (`/`, WebSocket, протокол [y-webrtc](https://github.com/yjs/y-webrtc)). Знакомит устройства, чтобы они синхронизировали прогресс напрямую по WebRTC. Ничего не хранит.
2. **Зашифрованные копии прогресса** (`/v1/blob/`, SQLite). Устройства хранят копию, поэтому им не нужно быть открытыми одновременно, а прогресс можно восстановить на новом устройстве. Копия сжимается и шифруется AES-GCM **на устройстве**, ключ выводится из секрета пары. Сервер получает нечитаемый блок и прочитать его не может.

В логи не пишутся ни комнаты, ни id копий, ни IP-адреса.

Сервер на Go — это один статический файл около 11 МБ (вместе с SQLite). Он занимает несколько МБ памяти и сам получает HTTPS-сертификат Let's Encrypt (autocert). Ничего, кроме него, на сервере не нужно: ни Node.js, ни nginx, ни Caddy.

| Файл | Что это |
|---|---|
| `main.go` | Запуск: HTTP или HTTPS с autocert, проверка Origin, `/healthz` |
| `hub.go` | Комнаты, пересылка сообщений, лимиты, ping/pong |
| `hub_test.go` | Тесты: изоляция комнат, публикация без подписки, лимиты, очистка, Origin |
| `store.go` | SQLite: копии с версиями, хеш токена записи, удаление устаревших, резервные копии |
| `api.go` | HTTP API копий, CORS, ограничение частоты запросов с одного IP |
| `api_test.go` | Тесты: создание, конфликт версий, чужой токен, удаление, лимиты, CORS, очистка, бэкап |
| `setup.sh` | Установка на Ubuntu: бинарник, служба systemd с ограничениями прав, порты, автообновления |
| `Makefile` | `make test`, `make build`, `make deploy HOST=…` |

## Защита

- **Origin.** Подключаться можно только с `https://astretartem.github.io` и с localhost. Другие сайты задаются флагом `-origins`.
- **Лимиты:**
  - 2000 соединений всего и 32 с одного IP;
  - 20 комнат на соединение;
  - сообщение не больше 64 КБ;
  - медленные клиенты отключаются.
- **Публикация** возможна только в комнату, на которую клиент подписан.
- **systemd:** временный пользователь без прав (`DynamicUser`), из привилегий только право занять порты 80 и 443, файловая система только для чтения, память ограничена 128 МБ.

## Разработка

```bash
make test
go run . -addr :4444
```

Для локальной разработки HTTPS не нужен: запустите `go run . -addr :4444` и подключайтесь к `ws://localhost:4444`.

## Установка на Oracle Cloud Always Free

1. Создайте машину **Canonical Ubuntu 24.04 Minimal** (Ampere A1 или AMD E2.1.Micro) и вставьте публичный ключ из `~/.ssh/oracle_greek.pub`.
2. В Networking → Virtual Cloud Network → Security List добавьте Ingress-правила: TCP 80 и 443, источник 0.0.0.0/0.
3. Разверните сервер:

```bash
make deploy HOST=<IP>
```

4. Проверьте:

```bash
curl https://<IP-через-дефисы>.sslip.io/healthz
```

Обновление делается той же командой `make deploy HOST=<IP>`.

## API копий

| Запрос | Ответ |
|---|---|
| `GET /v1/blob/{id}` | `200` данные и `ETag: "версия"` или `404` |
| `PUT /v1/blob/{id}` с `Authorization: Bearer <токен>` и `If-Match: "версия"` (`"0"` — создать) | `200 {"version":n}` · `409` (в `ETag` текущая версия) · `403` · `413` |
| `DELETE /v1/blob/{id}` с `Authorization: Bearer <токен>` | `204` · `403` · `404` |

`id` и `токен` — SHA-256 от секрета пары с разными префиксами. Сервер хранит только хеш токена. При `409` устройство скачивает свежую копию, объединяет её со своей и пишет снова: так ничего не теряется, даже если два устройства сохраняют одновременно.

## Хранение (SQLite)

- База: `/var/lib/private/greek-signaling/data.db` (WAL). Драйвер `modernc.org/sqlite` написан на чистом Go без cgo, поэтому сборка под ARM — одна команда.
- Раз в сутки сервер:
  - удаляет копии, которые не обновлялись **365 дней** (флаг `-keep-days`);
  - делает резервную копию базы (`VACUUM INTO`) в `backups/` и хранит последние 7.
- Лимиты:
  - копия не больше 1 МБ (обычно несколько сотен байт или КБ);
  - не больше 100 000 копий (`-max-blobs`);
  - 120 запросов в минуту с одного IP.
