# Сигнальный сервер для синхронизации прогресса

Устройства (компьютер и iPhone) синхронизируют прогресс напрямую через WebRTC. Этот сервер нужен только для того, чтобы они нашли друг друга. Он пересылает служебные сообщения внутри «комнаты» и **ничего не хранит и не пишет в логи** ни комнат, ни IP-адресов. Протокол совместим с [y-webrtc](https://github.com/yjs/y-webrtc).

Сервер на Go — это один статический файл около 8 МБ. Он занимает около 12 МБ памяти и сам получает HTTPS-сертификат Let's Encrypt (autocert). Ничего, кроме него, на сервере не нужно: ни Node.js, ни nginx, ни Caddy.

| Файл | Что это |
|---|---|
| `main.go` | Запуск: HTTP или HTTPS с autocert, проверка Origin, `/healthz` |
| `hub.go` | Комнаты, пересылка сообщений, лимиты, ping/pong |
| `hub_test.go` | Тесты: изоляция комнат, публикация без подписки, лимиты, очистка, Origin |
| `setup.sh` | Установка на Ubuntu: бинарник, служба systemd с ограничениями прав, порты, автообновления |
| `Makefile` | `make test`, `make build`, `make deploy HOST=…` |

## Защита

- **Origin.** Подключаться можно только с `https://astretartem.github.io` и с localhost. Другие сайты задаются флагом `-origins`.
- **Лимиты:**
  - 2000 соединений всего и 32 с одного IP;
  - 20 комнат на соединение;
  - сообщение не больше 64 КБ;
  - медленные клиенты отключаются.
- **Публикация** возможна только в комнату, на которую клиент подписан.
- **systemd:** временный пользователь без прав (`DynamicUser`), из привилегий только право занять порты 80 и 443, файловая система только для чтения, память ограничена 128 МБ.

## Разработка

```bash
make test
go run . -addr :4444
```

Для локальной разработки HTTPS не нужен: запустите `go run . -addr :4444` и подключайтесь к `ws://localhost:4444`.

## Установка на Oracle Cloud Always Free

1. Создайте машину **Canonical Ubuntu 24.04 Minimal** (Ampere A1 или AMD E2.1.Micro) и вставьте публичный ключ из `~/.ssh/oracle_greek.pub`.
2. В Networking → Virtual Cloud Network → Security List добавьте Ingress-правила: TCP 80 и 443, источник 0.0.0.0/0.
3. Разверните сервер:

```bash
make deploy HOST=<IP>
```

4. Проверьте:

```bash
curl https://<IP-через-дефисы>.sslip.io/healthz
```

Обновление делается той же командой `make deploy HOST=<IP>`.

## SQLite

Сигнальному серверу база не нужна. Когда появятся функции, которые что-то хранят (например, сообщения «тут ошибка» от пользователей), будем использовать SQLite через `modernc.org/sqlite`. Это чистый Go без cgo, поэтому сборка под ARM останется одной командой.
