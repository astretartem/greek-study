# Ελληνικά — тренажёр новогреческого (A2 / B1)

Локальный сайт без сборки и зависимостей. Прогресс хранится в браузере (localStorage).

## Запуск

- Самое простое: открыть `index.html` двойным кликом.
- Или запустить локальный сервер: двойной клик по `start.command` (или `python3 -m http.server 8765` в этой папке), потом открыть http://localhost:8765

Для озвучки нужен греческий голос: **Системные настройки → Универсальный доступ → Устная речь → Системный голос → Управлять голосами → Ελληνικά (Melina)**.

## Что есть

| Раздел | Что внутри |
|---|---|
| **Карточки** | Слова, глаголы, фразы; греческий→русский, русский→греческий; интервальное повторение по Лейтнеру (6 коробок: сегодня, через 1 / 3 / 7 / 16 / 35 дней) |
| **Глаголы** | Тренажёр отдельных форм, заполнение всей таблицы, таблицы спряжения. A2: настоящее, аорист, будущее, паратактикос. B1: + будущее длительное, перфект |
| **Правописание** | Диктант (на слух), перевод с письмом, выбор правильного написания (ι/η/υ/ει/οι, ε/αι, ο/ω, двойные согласные, ударение), постановка ударения, род существительных |
| **Словообразование** | 43 приставки и суффикса (ξανα-, ξε-, παρα-, συν-, α-/αν-, -ση, -μα, -τής/-τρια, -είο, -ικός, -ινος, -μένος, -εύω…) с 371 примером, 22 семьи однокоренных слов. Упражнения: «Угадай значение», «Какой аффикс?», «Образуй слово», «Лишнее слово». В словаре у слова показаны его состав и однокоренные |
| **Справочник** | Алфавит, правила орфографии и ударения, артикли, склонение, местоимения, группы глаголов, образование времён, повелительное (B1) |
| **Прогресс** | Статистика, активность, экспорт и импорт прогресса |

Переключатель **A2 / B1** в шапке: A2 = слова A1–A2, B1 = все слова и дополнительные времена.

## Ввод греческого

Греческая раскладка не нужна: при включённой настройке латинские буквы превращаются в греческие
(a→α, b→β, g→γ, d→δ, e→ε, z→ζ, h→η, u→θ, i→ι, k→κ, l→λ, m→μ, n→ν, j→ξ, o→ο, p→π, r→ρ, s→σ, t→τ, y→υ, f→φ, x→χ, c→ψ, v→ω).
Ударение: `;` перед гласной (`;a` → ά), диерезис: `:` (`:i` → ϊ). Конечная σ → ς ставится автоматически.

## Откуда словарь

Около 1880 единиц: 292 глагола, 985 существительных, 205 прилагательных, 260 служебных слов и чисел, 142 фразы. Все слова сверены с Викисловарём (kaikki.org, el.wiktionary), спряжения — с его таблицами (6064 формы совпали, расхождения разобраны вручную).

1. **Темы** взяты из программы экзаменов на сертификат знания греческого (Πιστοποίηση Ελληνομάθειας) [Центра греческого языка](https://www.greek-language.gr/certification/node/13.html), уровни A1, A2, B1. Те же экзамены проходят и на Кипре. Сертификаты A2/B1 [Университета Кипра](https://www.ucy.ac.cy/mogr/?p=2403) принимаются для натурализации.
2. **Корпус:** 24 [официальных образца экзаменов ΚΕΓ](https://www.greek-language.gr/certification/node/12.html) (чтение, аудирование, письмо, говорение; A1 для взрослых, A2, B1). Из PDF извлечено около 48 тыс. словоупотреблений.
3. **Частотность:** [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (OpenSubtitles 2018, 50 тыс. форм).
4. Для каждого слова сгенерированы все формы (падежи, числа, все времена глаголов) и сверены с корпусом. Результат лежит в `js/data-exam.js`:
   - отметка **ΚΕΓ** и фильтр «Только из экзаменов» (1029 слов);
   - уровень понижается на одну ступень, если слово встретилось ≥ 3 раз в экзамене более низкого уровня;
   - частые слова экзаменов, которых не было в словаре, добавлены (φορά, εικόνα, πληροφορία, ταιριάζω…).

Переводы и деление на темы сделаны вручную. Формы глаголов строит `js/greek.js`, неправильные формы заданы явно.

## Как добавить слова

- `js/data-nouns.js` (существительные), `js/data-vocab.js` (прилагательные, наречия, фразы): строка `греческий | русский | уровень`.
- `js/data-morph.js` (словообразование): строка `производное | перевод | исходное слово | перевод исходного`.
- `js/data-verbs-extra.js`: `глагол | перевод | уровень | будущее`. Аорист и паратактикос выводятся сами; неправильные формы указываются 5-м и 6-м полем.
